# Contributing

Thanks for helping improve GCA Practice.

1. Read the [implementation specification](implementation-plans/gca_practice_codex_implementation_spec.md).
2. Keep the application local, single-user, and within its existing architecture.
3. Add or update tests with each behavior change.
4. Run `npm run typecheck`, `npm test`, `npm run build`, and relevant Playwright tests.
5. Open a focused pull request explaining the user-visible change and validation performed.

Do not weaken import/oracle validation, expose hidden test data to the frontend,
or add proprietary assessment questions or branding.
